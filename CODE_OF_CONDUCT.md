# Code of Conduct

RawJobs follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good faith, and keep discussion about the work.

It applies in issues, pull requests, Discussions and anywhere else you represent the project.

To report a problem, contact the maintainer, [@Tanmay-Mhatre](https://github.com/Tanmay-Mhatre), using the email on their GitHub profile. Reports are kept private, and you'll get a reply within 7 days.
